# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within `react-native-foldface`, please report it responsibly.

Please send a report to https://github.com/mohamedelandy/react-native-foldface/security/advisories/new. We will acknowledge your report within a reasonable timeframe.

## Supported Versions

Version 1.x is currently supported with security updates.

## What to Include in Your Report

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- A proposed fix if you have one.

We appreciate your efforts to responsibly disclose your findings, and will investigate all valid reports.
